# YouTube Downloader Web App

A clean, responsive Flask web application for downloading YouTube videos, audio, and playlists powered by \yt-dlp\.

## Features
- Single video and complete playlist downloads.
- Audio extraction (MP3 / best audio format).
- Quality selection and format detection.
- Real-time download progress bar and status tracking.

## Usage
1. Install requirements:
   \\\ash
   pip install flask yt-dlp
   \\\
2. Start the downloader:
   \\\ash
   python app.py
   \\\
   Or double-click \un.bat\.
